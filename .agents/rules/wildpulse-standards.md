# WildPulse Engineering & Swarm Standards

1. **Zero Hardcoded Vendor/Model Release IDs**: Never embed specific model version identifiers or vendor release strings anywhere in `.agents/`, `src/`, `server/`, `scripts/`, `tests/`, `plans/`, configs, or documentation. Use only capability tiers (`inherit`, `pro`, `flash`) in agent specs.
2. **PowerShell Node v22 Path**: When running terminal commands on Windows in fresh sessions, prepend `C:\Users\alexg\AppData\Local\nodejs-v22` to `$env:PATH`.
3. **Strict TypeScript Hygiene**: Enforce `"strict": true` and `"noImplicitAny": true` across both client (`tsconfig.app.json`) and server (`tsconfig.server.json`). Zero `@ts-ignore`, zero unhandled promise rejections, zero uncaught console errors or `pageerror` exceptions.
4. **Honest Feed Provenance & Researcher Attribution**: Every animal record and Bio-Dossier view MUST display an explicit provenance badge (`LIVE API`, `CACHED`, or `DEMO FEED`) and researcher attribution (`studyTitle`, `principalInvestigators`, `institution`, `studyUrl`, `licenseTerms`). Never mask simulated/seed data as live telemetry.
5. **60fps Playback Isolation**: Never place 60fps animation frame timestamps in top-level React component state. Drive `requestAnimationFrame` ticks through `src/store/playbackClock.ts` and update MapLibre GeoJSON sources (`source.setData(...)`) and SVG playback cursors imperatively without triggering React tree re-renders.
6. **Subpath-Safe Asset Resolution**: Never hardcode root-relative `/data/...` or `/api/...` URLs in browser fetchers. Always resolve relative to `import.meta.env.BASE_URL` / `document.baseURI` so both `http://localhost:5173/` and `https://<user>.github.io/<repo>/` work identically.
7. **Antimeridian (`±180°`) Safety**: All geodesic distance calculations, trajectory GeoJSON polylines, uncertainty rings, and temporal interpolations MUST take the shortest longitudinal arc and split segments crossing `±180°` cleanly.
8. **Single-Owner File Discipline**: During parallel swarm tracks, workers edit strictly within their assigned directory ownership and never modify shared contracts locked in Phase 1.
