# WildPulse: Live Wildlife Telemetry & Bio-Logging Portal — Master Blueprint

## 1. Mission & Dual-Mode Architecture
WildPulse is a dual-mode isomorphic Conservation Mission Control application built for Greg:
- **Local Full-Stack Mode (`npm run dev` / `npm start`)**: Express TypeScript Telemetry Proxy (`127.0.0.1:3001`) + Vite React/MapLibre GL JS HUD (`127.0.0.1:5173`), featuring serialized 1-concurrent-request Movebank queueing, 2-tier disk/memory TTL caching, `license-md5` study terms handshakes, live Movebank Study ID importing, and IOOS ATN ERDDAP marine tracks.
- **GitHub Pages Unleashed Mode (`./` relative subpath static bundle)**: Hydrates `./data/ci-live-snapshot.json` (generated by `scripts/harvest-telemetry.ts` in CI every 6 hours), queries CORS-enabled live endpoints directly from the browser (IOOS ATN ERDDAP `.json`, Open-Meteo Weather & Marine, iNaturalist, GBIF, Wikipedia REST, BigDataCloud reverse-geocode), computes kinematics & 60fps interpolation inside a dedicated WebWorker, and falls back seamlessly to the scientifically authentic 10-animal `public/data/fallback-fleet.json`.

## 3. Shared Data Contracts (`src/types/telemetry.ts`)
- **`TelemetryFix`**: Normalized GPS / Argos / Archival coordinate fix with `timestampMs`, `lat`, `lon`, `altitudeOrDepthMeters` (`+` = airborne/ridge height, `-` = ocean depth, `null` = unknown), `groundSpeedKmh`, `speedIsDerived`, `headingDeg`, `externalTempC`, `tagVoltage`, `argosLc`, `accuracyRadiusMeters`, `sensorType`, `segmentDistanceKm`, and `isOutlierSpike`.
- **`AnimalDossier`**: Full individual profile merging `latestFix`, sorted `fixes[]`, derived `kinematics`, `ecology`, `environment`, `attribution`, `feedStatus` (`LIVE_API` | `CACHED` | `DEMO_FEED`), `sourceProvider`, and `diagnosticStatus` (`OK` | `LICENSE_REQUIRED` | `AUTH_REQUIRED` | `TAG_SILENT` | `RATE_LIMITED`).
- **60fps Scrubber Isolation**: High-frequency playback frames flow through `playbackClock` (`src/store/playbackClock.ts`) via `subscribeTick()` rather than Zustand/React state so MapLibre GeoJSON sources and SVG playback cursors update smoothly at 60fps without re-rendering HUD panels.

## 4. Proxy REST Contract (`server/app.ts`)
- `GET /api/health` -> `ProxyHealthResponse` (`status: 'ok'`, `movebankAuthConfigured`, `queueDepth`, `cacheEntries`, `uptimeSeconds`, `timestampIso`)
- `GET /api/fleet` -> `FleetResponse` (`generatedAt`, `connectionMode: 'PROXY_LIVE'`, `animals: AnimalDossier[]`, `sourceSummary`)
- `GET /api/studies/:studyId` (query `?licenseMd5=<hex>` optional) -> `StudyImportResponse` (`studyId`, `diagnosticStatus`, `feedStatus`, `animals`, `licenseTermsText`, `licenseMd5`, `message`)
- `GET /api/atn/marine` -> `FleetResponse` (curated live IOOS ATN ERDDAP marine tracks)

## 5. Kinematics, Antimeridian & Keyboard Invariants
- **Antimeridian Shortest Arc**: `deltaLon = ((lon2 - lon1 + 540) % 360) - 180` for Haversine distances and temporal interpolation; `splitTrackAtAntimeridian` splits GeoJSON `LineString` segments crossing `|lon2 - lon1| > 180` cleanly at `+180°` and `-180°`.
- **Argos Uncertainty Radii**: `G: 35m`, `3: 250m`, `2: 500m`, `1: 1500m`, `0: 3000m`, `A: 5000m`, `B: 10000m`, `Z: 15000m`.
- **Keyboard Shortcuts**:
  - `[`: Toggle Left Fleet Discovery Panel
  - `]`: Toggle Right Animal Bio-Dossier Drawer
  - `Space`: Play / Pause Migration Playback (ignored inside inputs/textareas)
  - `F`: Toggle Follow-Cam tracking
  - `Esc`: Close Study Importer modal or clear active selection
  - `1–4`: Switch Basemaps (`1` Dark Tactical, `2` Satellite, `3` Terrain, `4` Ocean Bathymetry)
